# Полные проекты electroperedachi с паспортом рейвера

Это полные исходники и статические ресурсы проекта, включая внесённые изменения. Каждый архив распаковывается в отдельную папку client, admin или back. Архивы с изменениями больше не нужны для установки этой версии.

Не включены: настоящие .env/ключи, node_modules, результаты сборки, служебные файлы macOS, список email из controllers/emails.txt и ранее сгенерированные персональные билеты. Шаблоны билетов сохранены.

Используйте Node.js 20 или новее. Установите зависимости через npm ci в каждой папке.

Для client скопируйте .env.example в .env.local, укажите адрес API и выполните npm run dev или npm run build / npm start.
Для admin скопируйте .env.example в .env.local, укажите адрес API и выполните npm start или npm run build.
Для back скопируйте .env.example в .env, укажите подключения и секреты, затем npm run dev или npm start. Для баллов нужна MongoDB replica set. Настройте origins и соответствующие адреса сайта/API. Для фоновой обработки после проверки включите PASSPORT_WORKER_ENABLED=true. Рассылки по умолчанию выключены.

Бесплатные билеты 0 грн и оплата полностью баллами не начисляют новые баллы. Возврат билетов исключён по политике проекта.

Оплата изменена: проверка подписи LiqPay, серверный расчёт скидок/баллов, защита повторной обработки. Рабочую базу, оплату и почту в этой сессии не использовали. Реальную цепочку оплаты → билет → письмо ещё нужно проверить на отдельном тестовом окружении перед переносом на рабочий сайт.

Подробности реализации, проверок и ограничений находятся в README-PASSPORT.md в каждом архиве.
