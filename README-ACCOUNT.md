Личный кабинет и навигация

Кабинет теперь /account; /passport перенаправляет на него.
В обычной шапке восстановлены ссылки и добавлена иконка кабинета.
На кастомных лендингах меню остаётся скрытым.
Полоса прокрутки вкладок тонкая (3px), серая.
Главная обрабатывает отсутствующие списки API без ошибки индекса.

Архив содержит полный клиент со всеми предыдущими изменениями бонусов и QR.
.env и node_modules не включены: сохраните свой .env, установите зависимости.
Проверено: синтаксис, мобильный и широкий экран, загрузка главной с пустыми списками.
